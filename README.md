 🛡️ 暗夜守护者

> 吸血鬼幸存者风格 · 浏览器即玩的 HTML5 小游戏

 🚀 如何开始

不需要安装任何东西！** 双击 `index.html` 即可在浏览器中游玩。



 🎮 操作说明

| 按键 | 功能 |
|------|------|
| W A S D 或方向键 | 移动角色 |
| 空格 | 冲刺（短暂冷却后可用） |
| R | 死亡后快速重开 |


 📖 游戏规则

核心机制
 你控制**绿色守护者**，敌人从屏幕四周涌来
 你**不需要主动攻击**——角色自带旋转的**护身盾**（黄色光球）
 护身盾碰到敌人 → 敌人消灭，**+10 分**
 你碰到敌人 → **生命 -1**，被击退，短暂无敌

 生命与失败
 初始 **5 条命**，归零则游戏结束
 死亡后可在**当前关卡重来**，或从第一关重新开始



 🗺️ 三关卡

| 关卡 | 通关分数 | 特色 |
|------|----------|------|
| 🌿 **暗夜森林** | 100 分 | 基础敌人 + 树木障碍 |
| 🔥 **烈焰之地** | 200 分 | 巨型坦克敌人(2HP) + 岩浆池 |
| 🌌 **虚空领域** | 300 分 | 法师射弹 + 幽灵瞬移 + 虚空裂隙 |



 🎁 奖励与成长

| 方式 | 说明 |
|------|------|
| ⏱️ 定时升级 | 每 25 秒自动 +1 护身盾 |
| 💎 灵魂碎片 | 杀敌掉落，**集 5 个 +1 护身盾** |
| 💚 生命之心 | 拾取回复 1 点生命 |
| ⚡ 速度 Boost | 5 秒内移速翻倍 |
| 🛡️ 护盾道具 | 5 秒内不受任何伤害 |



 💾 存档功能

 浏览器自动存档，**关闭后重开可继续**
通关任意关卡自动保存进度
 主菜单会显示"继续游戏"按钮（有存档时）



 🔧 技术说明

 纯 HTML5 Canvas + JavaScript，无需服务器
 支持所有现代浏览器（Chrome / Edge / Firefox）
 文件大小约 30KB，可用 U 盘、网盘、微信等方式分享
